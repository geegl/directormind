# 关门以后：她也在作决定

原创样例，文本在本轮比较中固定；不属于私有项目剧本。作者：DirectorMind 本轮示范。

人物：NING：宁，负责接预约的合伙人。ZHOU：舟，负责修补的合伙人。两人都是成年人。

修补店内，工作台两侧。夜，打烊后。

<a id="BEAT-01"></a>

宁停下手里的铅笔，看着舟。

NING: 明天的预约，我还接吗？

<a id="BEAT-02"></a>

舟看向门，捏紧围裙又松开，把手放到膝上。宁同时开始折起桌上的预约纸。

ZHOU: 不是房东要收回。

舟看见宁折纸，抬头。

ZHOU: 是我先打的电话。

宁把纸的边缘压齐。

<a id="BEAT-03"></a>

宁低头看了一眼铅笔，再抬头。

NING: 那你为什么让我去买新灯？

<a id="BEAT-04"></a>

ZHOU: 我以为买回来，就舍不得关了。

<a id="BEAT-05"></a>

宁把铅笔放回笔筒。两人都没有起身。

<a id="BEAT-06"></a>

这次改写的时间关系锁定：折纸从舟回避视线时开始，到他说完主动拨电话才完成。
