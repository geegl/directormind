# 门还开着

原创样例，文本在本轮比较中固定；不属于私有项目剧本。作者：DirectorMind 本轮示范。

人物：MEI：梅，留任的成人志愿者。YU：余，准备退出的成人志愿者。

社区活动室。傍晚。

<a id="BEAT-01"></a>

梅坐在门路上的椅子里，余坐在她对面。

MEI: 你把钥匙留下，就算说完了？

余的掌心摊开。

YU: 你每次都先替我说完。

<a id="BEAT-02"></a>

梅把抓着椅背的手放下。

MEI: 那你说。

<a id="BEAT-03"></a>

余起身，绕过梅的椅子，走到门口，停在门内。

YU: 我今天没有力气了。

<a id="BEAT-04"></a>

梅起身，把椅子挪到墙边。

MEI: 我没要你今天留下。

余回头看梅。门开着，她没有跨出去。
