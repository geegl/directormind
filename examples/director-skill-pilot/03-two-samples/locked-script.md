# 差了一指

原创样例，文本在本轮比较中固定；不属于私有项目剧本。作者：DirectorMind 本轮示范。

人物：LAN：岚，成人学徒。TAO：陶，成人师傅。使用两段原创灰色织带作为工序样件。

小型戏服修整间。下午。

<a id="BEAT-01"></a>

岚和陶各拿着一段灰色织带。

LAN: 我照着它裁的，怎么会短？

<a id="BEAT-02"></a>

陶把两段织带放到桌面，近端齐平，远端差出一指宽。

TAO: 先把这头放齐。

<a id="BEAT-03"></a>

岚沿着织带看到另一头。陶按着起点，没有拉扯织带。

<a id="BEAT-04"></a>

TAO: 短的这条我洗过。不是你裁错。这个我重做。

陶拿起短条，岚把手从长条边移开。
