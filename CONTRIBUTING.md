# Contributing

## Branches

Use `codex/<host>-<topic>`. Pull `main` before selecting a new scene and search existing evidence IDs first.

## One research change per commit

A useful research commit normally contains one of:

- one complete scene evidence file;
- one evidence audit/correction;
- one grammar proposal backed by existing evidence IDs;
- one compiler/validator change with its smallest relevant check.

Do not combine unrelated scene analyses or overwrite another agent's evidence file.

## Pull requests

State:

- scene problem addressed;
- evidence files added or audited;
- grammar rules added, changed, rejected, or left UNKNOWN;
- validations run;
- raw media exclusion confirmed.

`main` is the integrated, reviewed state. Structural checks do not replace human creative review.
